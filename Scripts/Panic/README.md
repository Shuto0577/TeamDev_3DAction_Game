# 焦り度検知システム（Scripts/Panic）

プレイヤーの操作から「焦り」を検知し（Detection）、ボスがその焦り方に合わせて攻め方を変える（BossPressure）仕組みのスクリプトです。

> プロジェクトからの抜粋のため、`PlayerController` や `EnemyBaseController` など、ここに含めていないクラスを参照しています。単体ではコンパイルできません。

[← READMEに戻る](../../README.md)

## 全体の流れ

```
毎フレーム
  PanicDetector が観測値を PanicContext に詰める
      ↓
  8つの指標（PanicSignal の派生クラス）が、それぞれ焦りの兆候を判定してスコア（0〜1）を出す
      ↓
  PanicScoreCalculator が合算して、総合焦り度と系統ごとの焦り度（0〜100）を出す
      ↓
  PanicLevelTracker が段階（平常 / 動揺 / 焦り）に変換する
      ↓
  TBossPanicPressure が段階と系統から追い込み方を決め、ボスの各行動に補正値を掛ける
```

## Detection（プレイヤー側：焦りを見抜く）

### 統括

| ファイル | 役割 |
| --- | --- |
| `PanicDetector.cs` | まとめ役。毎フレームの観測値の収集、入力・被弾などのイベントの各指標への受け渡し、結果（焦り度・段階・系統）の公開だけを行い、判定や合算は他のクラスに任せる |

### 指標の土台

| ファイル | 役割 |
| --- | --- |
| `PanicSignal.cs` | 8つの指標の共通の親クラス。系統・表示名・スコア・毎フレームの計測（`Tick`）・リセットを定義する |
| `PanicContext.cs` | 1フレーム分の観測値（交戦中の敵、敵との距離・向き、移動入力、速度、弓を構えているか など）。指標がプレイヤーや敵のコンポーネントを直接読まず、何を根拠に判定したかをここに集める |
| `PanicEngagementTracker.cs` | 計測の対象になる「交戦相手」を決める。最寄りの敵を毎フレーム選び直すだけだと、索敵範囲の外へ逃げた瞬間に相手がいなくなり逃避を測れないため、一度交戦した敵は離れきるか警戒を解くまで持ち続ける |

### 8つの指標

| ファイル | 指標 | 系統 | 判定の内容 |
| --- | --- | --- | --- |
| `FlightSignal.cs` | 逃避 | 逃げ腰 | 交戦中の敵から遠ざかり続けた時間。背を向けて離れるのを最も重く、敵を向いたまま下がるのは軽く数え、弓を構えたまま下がる「引き撃ち」は正しい戦法として数えない |
| `TrapSignal.cs` | 空間喪失 | 逃げ腰 | 敵が近いのに、移動入力をしても思うように動けない時間。壁や地形に追い詰められた状態を拾う。探索中の引っかかりや、敵の体に押し当てているだけの状態は除く |
| `GuardSpamSignal.cs` | スパム | 防御崩れ | 剣の防御ボタンを押す頻度。ボスの攻撃中の連打はパリィを狙った正しい操作と区別できないため数えず、何も来ていない時の連打だけを数える |
| `HitChainSignal.cs` | 回避失敗 | 防御崩れ | 直近の被弾回数。2回の被弾は焦っていなくても起きるため、3回で満点にしている |
| `AimCancelSignal.cs` | 意思崩壊 | 迷い | 弓を構えたのに撃たず、自分で解いた回数 |
| `AimJitterSignal.cs` | ジッター | 迷い | 弓を構えている間、照準が「行き過ぎては戻す」を繰り返した回数 |
| `WeaponThrashSignal.cs` | 武器切替 | 迷い | 短い時間に何度も武器を切り替えた回数 |
| `FreezeSignal.cs` | 硬直 | 硬直 | 敵の攻撃が始まってから終わるまで、近くにいたのに何もしなかった回数。攻撃が終わった時点でまとめて判定するので、ぎりぎりまで引きつけてからパリィや回避をする上手な操作は数えない |

### 合算と段階

| ファイル | 役割 |
| --- | --- |
| `PanicScoreCalculator.cs` | 8つのスコアを合算する。式は「どれか1つでも当たっている確率」（soft-OR）：`焦り度 = 100 × (1 − Π(1 − 重み × スコア))`。複数の指標がそろうほど100に近づくが超えず、指標を増やしても式を直す必要がない。上がる時は速く、下がる時はゆっくり追従させる |
| `PanicLevelTracker.cs` | 焦り度を段階に変換する。境目の前後で数値が揺れても段階が毎フレーム切り替わらないよう、上がる時と下がる時の境目をずらしている（ヒステリシス）。下がる時だけ最低保持時間を設け、焦りが一瞬途切れただけでボスが攻めを緩めないようにしている |
| `PanicLevel.cs` | 段階の定義（平常 / 動揺 / 焦り）。AIは数値ではなく段階で判断する（数値のまま使うと判断が毎フレーム揺れるため） |
| `PanicCategory.cs` | 系統の定義（逃げ腰 / 防御崩れ / 迷い / 硬直）。ボスが「何に焦っているか」に合わせて追い込み方を変えるための単位 |

### 調整用

| ファイル | 役割 |
| --- | --- |
| `PanicSessionLogger.cs` | しきい値や重みを実際のプレイから調整するため、各指標の値を一定間隔でCSVに記録する開発用コンポーネント。プレイヤーが「今焦った」と感じた瞬間に印を付けられ、その前後でスコアがどう動いたかを見て、取りこぼしや誤検知を調べる。エディターと開発ビルドでのみ動く |

## BossPressure（ボス側：焦りを突く）

| ファイル | 役割 |
| --- | --- |
| `TBossPanicPressure.cs` | 段階と系統から「今どう追い込むか」を決め、攻撃間隔・攻撃の選ばれやすさ・間合い・追跡のしつこさなどに掛ける補正値を返す。状態は なし / 軽い追い込み / 追い込み / 息継ぎ の4つ。追い込みは最大8秒・2発までで、必ず息継ぎを挟む |
| `TBossPanicPressureSettings.cs` | 追い込みの設定値。系統ごとの攻め方（逃げ腰には触手で引き戻してしつこく追う、硬直には出の速い攻撃を畳みかける など）と、歯止め（最大時間・命中数・息継ぎの長さ・合図から攻撃までの間）を Inspector で調整できる |
| `TBossPressureProfile.cs` | 系統1つ分の追い込み方。攻撃間隔の倍率、様子見を挟まず突っ込む確率の下限、通常攻撃・鎌・触手それぞれの選ばれやすさの倍率、間合いを詰めるか、見失ってから諦めるまでの時間の倍率、の7つの補正値を持つ |
| `TBossPressureMode.cs` | 追い込みの状態の定義（なし / 軽い追い込み / 追い込み中 / 息継ぎ）と、デバッグ表示・ログ用の日本語名 |

## 試行錯誤で変えたところ

- **ジッター**：最初は照準を動かす速さで判定していましたが、動き回るボスを素早く正確に追う正常な操作でも値が上がり、マウスとパッドでも値の出方が大きく違いました。慌てた照準は「狙いすぎて戻す」切り返しとして現れるため、切り返した回数で判定する方式に変えました。
- **回避失敗**：最初は「前の被弾から3秒以内なら連鎖」と数えて2回で満点にしていましたが、2回の被弾は焦っていなくても起きるため、直近の時間内の回数で数え、満点を3回に変えました。
- **合算の式**：最初は各指標の平均を取っていましたが、指標の数を増やすたびに目盛りが変わってしまうため、soft-ORの式に変えました。
